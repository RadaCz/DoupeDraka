# Repository tools

This folder is reserved for maintained developer utilities.

The former `brain_step1.py` and `step1_patch.py` scripts are in `archive/`.
They were one-off documentation/patch helpers for an earlier repository step and
are preserved for history only; do not run them against the current source tree.

The maintained encounter calculator is part of the application at
`app/engine/tools.py` and is covered by the application tests.
